# Enterprise 26.1 Professional Executive Writing

Version: `26.1.0`
Date: 2026-07-29

This release replaces extractive-looking Executive AI output with original,
audience-specific professional Arabic. It adds nine executive-writing profiles,
semantic interpretation before drafting, separate supporting quotations, and a
direct-paragraph-copy guard.

Enterprise 25 retrieval and confidentiality are unchanged. Enterprise 24
extraction is unchanged. There is no database migration, new permission,
external provider, environment variable, or Hostinger entry-file change.

Production acceptance requires green CI and live verification of all nine
profiles, separate quotations and source links, insufficient-evidence refusal,
and confidential-source denial.
