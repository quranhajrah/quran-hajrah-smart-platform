# Documentation

This directory contains architecture decisions, API/module contracts, deployment notes, release reports, operating guides, and recovery procedures.

Current production modules:

- Identity, authentication, users, roles, permissions, and audit logging.
- Enterprise 22 Institutional Knowledge Center.
- Enterprise 23 Executive Intelligence Platform.
- Enterprise 24 Institutional Document Intelligence Engine.
- Enterprise 24.1 deterministic institutional semantic extraction.
- Enterprise 24.2 production-structure logical assembly and regression validation.

Start with `enterprise-24-document-intelligence.md`, then use `enterprise-24-review-and-import.md`, `extraction-methodology.md`, and `source-traceability.md`. Local validation and the production acceptance state are recorded in `phase-24-document-intelligence-validation-report.md`.

For the 24.1 Arabic reconstruction, semantic mapping, proposal quality gates, relation-aware import, limitations, and production UAT sequence, see `enterprise-24-1-semantic-extraction.md`.

For the 24.2 multiline/RTL logical assembler, split table headers, merged cells, stale-error fix, and live acceptance checklist, see `enterprise-24-2-semantic-assembly.md`.

Local 24.1 command results and the still-pending production acceptance conditions are recorded in `phase-24-1-semantic-extraction-validation-report.md`.

Local 24.2 results and its explicitly pending live reanalysis are recorded in `phase-24-2-validation-report.md`.
